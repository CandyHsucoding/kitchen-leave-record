# 廚工補休時數紀錄與年底結算

學校廚工的年度特休／補休登記工具（單一 HTML 檔，資料存在瀏覽器）。

- **紀錄登記**：多位廚工切換，每人每年度記錄職別、姓名、年度特休、月薪與每天請休時數
- **年底結算**：計算尚未休完的特休與不休假加班費（月薪 ÷ 30 ÷ 8 × 未休時數，四捨五入至元），可列印或匯出 CSV
- **空白表列印**：年底印出新年度空白紀錄表，假日依人事行政總處辦公日曆表預先標註
- **假日設定**：內建 115、116 年假日，可自行增修
- **匯出／匯入備份檔**：Excel（.xlsx）格式，可直接用 Excel 開啟查看；也可匯入舊的 .json 備份與 worktool4 的資料（視為 115 年）
